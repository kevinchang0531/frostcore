# 霜核戰域 Frostcore

原創科幻即時戰略遊戲（Unity 6 網頁版），開發中。

**開始玩：https://kevinchang0531.github.io/frostcore/**

冰封行星「霜核」的地心有一顆還在發熱的地熱核心。鑽井公司帶著機具來開採，世代住在冰層裡的冰裔起身守護，雙方在冰原上爭奪熱泉與晶礦。

## 目前進度：第一階段（操作試玩）

現在可以做的事：在一張 96×96 格的冰原地圖上框選、編隊、指揮部隊行軍，單位會自己繞過冰岩找路。
**還沒有**採集、建造、戰鬥和電腦對手，這些會在後面的階段加上。

## 操作

| | 電腦 | 手機／平板 |
|---|---|---|
| 選取 | 左鍵點選、拖曳框選（Shift 加選） | 點單位、一指拖曳框選 |
| 移動 | 右鍵點地面或小地圖 | 選好後點地面 |
| 鏡頭 | 方向鍵、滑鼠推到螢幕邊、滾輪縮放 | 兩指拖曳移動、兩指開合縮放 |
| 其他 | S 停止、Ctrl+數字編隊、數字叫出編隊、N 加 10 個單位 | 右下角「全選／取消／停止」按鈕 |

點小地圖可以把鏡頭跳過去。第一次載入約 20 MB。

名稱、世界觀、陣營、美術全部原創；玩法類型參考經典科幻即時戰略。這個 repo 只放網頁版匯出檔。
