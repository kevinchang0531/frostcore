# 霜核戰域 Frostcore

原創科幻即時戰略遊戲（Unity 6 網頁版），開發中。

**開始玩：https://kevinchang0531.github.io/frostcore/**

冰封行星「霜核」的地心有一顆還在發熱的地熱核心。鑽井公司帶著機具來開採，世代住在冰層裡的冰裔起身守護，雙方在冰原上爭奪熱泉與晶礦。

## 目前進度：第二階段（蓋基地）

現在可以做的事：
- 開局有一座鑽井平台和 6 個鑽探工，鑽探工會自己去採晶礦。
- 選鑽探工蓋宿舍艙（加人口）、兵營、熱泉幫浦（蓋在熱泉上才能採熱能）、第二座鑽井平台。
- 選鑽井平台生產鑽探工，選兵營生產冰原步兵；可以設定集結點，人口滿了要先蓋宿舍艙。
- 框選、編隊、指揮部隊行軍，單位會自己繞過冰岩和建築找路。

**還沒有**戰鬥、戰爭迷霧和電腦對手（對角的冰裔目前只是站著），之後的階段會加上。

## 操作

| | 電腦 | 手機／平板 |
|---|---|---|
| 選取 | 左鍵點單位或建築、拖曳框選（Shift 加選） | 點單位或建築、一指拖曳框選 |
| 下指令 | 右鍵：點地面移動、點晶礦採集、點未完工建築接手 | 選好後點地面、晶礦或建築 |
| 建造 | 選鑽探工 → 按建築按鈕 → 左鍵選位置（右鍵或 Esc 放棄） | 選鑽探工 → 按建築按鈕 → 點地面 |
| 生產 | 選建築 → 按單位按鈕；右鍵設集結點 | 選建築 → 按單位按鈕；點地面設集結點 |
| 鏡頭 | 方向鍵、滑鼠推到螢幕邊、滾輪縮放 | 兩指拖曳移動、兩指開合縮放 |
| 其他 | S 停止、Ctrl+數字編隊、數字叫出編隊 | 右下角「全選／取消／停止」按鈕 |

點小地圖可以把鏡頭跳過去。第一次載入約 20 MB。

名稱、世界觀、陣營、美術全部原創；玩法類型參考經典科幻即時戰略。這個 repo 只放網頁版匯出檔。
