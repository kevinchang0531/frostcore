# 霜核戰域 Frostcore

原創科幻即時戰略遊戲（Unity 6 網頁版），開發中。

**開始玩：https://kevinchang0531.github.io/frostcore/**

冰封行星「霜核」的地心有一顆還在發熱的地熱核心。鑽井公司帶著機具來開採，世代住在冰層裡的冰裔起身守護，雙方在冰原上爭奪熱泉與晶礦。

## 目前進度：第四階段（完整兵種與科技）

現在可以做的事：
- 採晶礦和熱能（熱泉要先蓋幫浦）。熱能用來蓋高級建築、造坦克與飛行單位、研發科技。
- 八種建築：鑽井平台、宿舍艙、兵營、熱泉幫浦、供熱塔（會自己開火的砲塔）、重工廠、機棚、研究站。有些要先蓋好前置建築。
- 七種單位：鑽探工、冰原步兵、噴焰兵、雪地偵察車、熱熔坦克（拆建築很快）、旋翼砲艇（會飛）、醫療無人機（會飛、幫友軍補血）。
- 六項科技：武器強化 I／II、裝甲強化 I／II、步兵長槍管、興奮劑（步兵的技能，按 T 或按鈕）。
- 冰裔會一波一波來攻：第一波在 2 分 30 秒，之後每 75 秒一波，後面的波次會出現冰刺射手、冰甲巨獸和會飛的冰翼。噴焰兵和坦克打不到空中，要靠步兵、砲艇或供熱塔。
- 有戰爭迷霧。拆光對方所有建築（霜核巢和兩座冰刺柱）就獲勝；自己的建築全沒了就輸。

**還沒有**真正的電腦對手（冰裔只會照固定節奏派兵，不採礦也不蓋建築）和音效，之後的階段會加上。

## 操作

| | 電腦 | 手機／平板 |
|---|---|---|
| 選取 | 左鍵點單位或建築、拖曳框選（Shift 加選） | 點單位或建築、一指拖曳框選 |
| 下指令 | 右鍵：點地面移動、點敵人攻擊、點晶礦採集、點未完工建築接手 | 選好後點地面、敵人、晶礦或建築 |
| 攻擊移動 | A 鍵（或按鈕）再左鍵點目的地 | 「攻擊移動」按鈕再點目的地 |
| 建造 | 選鑽探工 → 按建築按鈕 → 左鍵選位置（右鍵或 Esc 放棄） | 選鑽探工 → 按建築按鈕 → 點地面 |
| 生產 | 選建築 → 按單位按鈕；右鍵設集結點 | 選建築 → 按單位按鈕；點地面設集結點 |
| 鏡頭 | 方向鍵、滑鼠推到螢幕邊、滾輪縮放 | 兩指拖曳移動、兩指開合縮放 |
| 其他 | S 停止、Ctrl+數字編隊、數字叫出編隊 | 右下角「全選／取消／停止」按鈕 |

點小地圖可以把鏡頭跳過去。第一次載入約 20 MB。

名稱、世界觀、陣營、美術全部原創；玩法類型參考經典科幻即時戰略。這個 repo 只放網頁版匯出檔。
